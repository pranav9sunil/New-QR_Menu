Printer Bridge Setup Guide (macOS Edition)

Architecture:
The Printer Bridge runs on your local Mac. Vercel talks to it via Localhost.
Cloud -> Browser (Mac) -> Bridge (Mac) -> Printers

1. Installation (Persistent Service)

We will set up the bridge to run automatically when you log in.

  1. Download and extract printer-bridge-mac-pro.zip to Documents.
  2. Open Terminal used Cmd+Space.
  3. Type cd and drag the folder into Terminal. Press Enter.
  4. Run this one-time setup command: 
    chmod +x setup_mac_service.sh && ./setup_mac_service.sh

You should verify it by opening http://localhost:3001.

2. Managing Printers

Network Printers

  • Get the IP address from a self-test page.
  • Add in Admin Panel: Type=Kitchen, IP=192.168.x.x, Port=9100.

USB Printers

  • Find the exact name in System Settings > Printers & Scanners.
  • Add in Admin Panel: Type=Receipt, Interface=USB/System, Name=[Exact Name].

3. Troubleshooting

  • Permission Denied: Run chmod +x setup_mac_service.sh.
  • Logs: Check bridge.log in the folder.
  • Service Control: Use launchctl unload / launchctl load with the plist path if needed.
