## 🔄 Changing Your Vercel URL

Yes! You have several options to change or customize your URL.

### Option 1: Add a Custom Domain (Recommended for Production)

**Best for:** Professional appearance, branding

**Examples:**
- `order.yourrestaurant.com`
- `menu.yourrestaurant.com`
- `yourrestaurant.com`

#### Step 1: Purchase a Domain
Buy a domain from any registrar:
- Namecheap: https://www.namecheap.com
- GoDaddy: https://www.godaddy.com
- Google Domains: https://domains.google
- Cloudflare: https://www.cloudflare.com

**Cost:** ~$10-15/year

#### Step 2: Add Domain to Vercel

**Via Vercel Dashboard:**
1. Go to: https://vercel.com/pranavsunil-3491s-projects/qr-restaurant-ordering
2. Click **"Settings"** tab
3. Click **"Domains"** in sidebar
4. Click **"Add"** button
5. Enter your domain: `order.yourrestaurant.com`
6. Click **"Add"**

**Via Vercel CLI:**
```bash
cd "/Users/pranav/User Files/ASU/Internship/QR Code again"
vercel domains add order.yourrestaurant.com
```

#### Step 3: Configure DNS Records

Vercel will show you DNS records to add. Go to your domain registrar and add:

**For Subdomain (e.g., order.yourrestaurant.com):**
```
Type: CNAME
Name: order
Value: cname.vercel-dns.com
TTL: Auto or 3600
```

**For Root Domain (e.g., yourrestaurant.com):**
```
Type: A
Name: @ (or leave blank)
Value: 76.76.21.21
TTL: Auto or 3600

Type: CNAME
Name: www
Value: cname.vercel-dns.com
TTL: Auto or 3600
```

#### Step 4: Wait for DNS Propagation
- Usually takes 5-30 minutes
- Can take up to 48 hours
- Vercel will automatically enable HTTPS

#### Step 5: Verify Domain
1. Go back to Vercel Dashboard → Domains
2. You should see ✅ next to your domain
3. Click **"Visit"** to test

#### Step 6: Regenerate QR Codes
**IMPORTANT:** After adding custom domain:
1. Login to admin panel at your NEW domain: `https://order.yourrestaurant.com/admin`
2. Go to "QR Codes" page
3. Download NEW QR codes (they'll now use your custom domain)
4. Replace old QR codes at tables

**Your new URLs:**
- Admin: `https://order.yourrestaurant.com/admin`
- Customer: `https://order.yourrestaurant.com/signup?tableId=table1`

### Troubleshooting Domain Setup

#### Issue: Domain not working after 30 minutes

**Check DNS:**
```bash
# Check if DNS is propagated
nslookup order.yourrestaurant.com

# Should show Vercel's IP or CNAME
```

**Solutions:**
1. Verify DNS records are correct
2. Wait longer (up to 48 hours)
3. Clear browser cache
4. Try incognito mode
5. Check Vercel Dashboard for errors

#### Issue: "Invalid Configuration" in Vercel

**Solutions:**
1. Ensure CNAME points to `cname.vercel-dns.com`
2. Remove any conflicting A records
3. Wait for DNS propagation
4. Contact Vercel support

#### Issue: HTTPS not working

**Solutions:**
1. Wait 5-10 minutes for certificate
2. Vercel auto-issues Let's Encrypt certificate
3. Check Vercel Dashboard → Domains for status
4. Force refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
